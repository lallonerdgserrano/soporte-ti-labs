# Soporte TI Labs

Laboratorios prácticos de **Soporte TI, Help Desk, redes, diagnóstico técnico y resolución de problemas**.

Este repositorio forma parte de mi portafolio técnico y está orientado a documentar escenarios relacionados con soporte técnico, análisis de fallas, redes y conectividad, sistemas operativos y procedimientos de atención de incidencias.

---

## Objetivo del repositorio

Demostrar habilidades prácticas en soporte TI mediante laboratorios documentados con:

- Objetivo técnico
- Escenario del problema
- Entorno utilizado
- Herramientas y comandos aplicados
- Diagnóstico realizado
- Solución aplicada
- Validación final
- Capturas de evidencia
- Documentación técnica o ticket
- Habilidades demostradas y valor laboral

---

## Áreas cubiertas

- Diagnóstico de red y conectividad
- Verificación de conectividad
- Comandos de Windows y Linux para soporte
- Resolución de problemas comunes
- Documentación técnica
- Buenas prácticas de Help Desk
- Atención, seguimiento y cierre de incidencias técnicas

## Propósito profesional

Este repositorio busca mostrar evidencia verificable de aprendizaje aplicado, pensamiento estructurado y capacidad para documentar procesos técnicos de forma clara y profesional.
