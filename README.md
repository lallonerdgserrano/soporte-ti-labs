# Soporte TI Labs

Laboratorios prácticos de **Soporte TI, Help Desk, diagnóstico técnico y resolución de problemas**.

Este repositorio forma parte de mi portafolio técnico y está orientado a documentar escenarios reales o simulados relacionados con soporte técnico, análisis de fallas, redes básicas, sistemas operativos y procedimientos de atención técnica.

---

## Objetivo del repositorio

Demostrar habilidades prácticas en soporte TI mediante laboratorios documentados con:

- Objetivo técnico
- Escenario del problema
- Herramientas utilizadas
- Pasos realizados
- Comandos aplicados
- Capturas de evidencia
- Resultado final
- Habilidades demostradas

---

## Áreas cubiertas

- Diagnóstico básico de red
- Verificación de conectividad
- Comandos de Windows y Linux para soporte
- Resolución de problemas comunes
- Documentación técnica
- Buenas prácticas de Help Desk
- Análisis inicial de incidentes técnicos

## Propósito profesional

Este repositorio busca mostrar evidencia verificable de aprendizaje aplicado, pensamiento estructurado y capacidad para documentar procesos técnicos de forma clara y profesional.

Cada laboratorio será actualizado conforme se complete, pasando de *(planificado)* a *(completado)* y enlazándose a su carpeta correspondiente dentro del repositorio.
