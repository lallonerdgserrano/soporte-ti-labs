# Diagnóstico básico de conectividad

**Estado:** En desarrollo  
**Área:** Soporte TI / Help Desk / Redes básicas  
**Objetivo:** Documentar un procedimiento básico para diagnosticar problemas de conectividad de red.

---

## Escenario

Un usuario reporta que su equipo tiene problemas para conectarse a internet o acceder a recursos de red.  
El objetivo del laboratorio es aplicar una secuencia básica de diagnóstico para identificar si el problema está relacionado con configuración IP, conectividad local, salida a internet o resolución DNS.

---

## Herramientas y comandos utilizados

- `ipconfig`
- `ping`
- `tracert`
- `nslookup`

---

## Procedimiento técnico

1. Verificar configuración IP del equipo.
2. Probar conectividad con la propia interfaz de red.
3. Probar conectividad con el gateway.
4. Probar conectividad hacia internet.
5. Verificar resolución DNS.
6. Documentar resultados y conclusión técnica.

---

## Evidencias a documentar

- Captura de configuración IP.
- Captura de prueba de ping.
- Captura de prueba hacia gateway.
- Captura de prueba hacia internet.
- Captura de prueba DNS.
- Conclusión del diagnóstico.
